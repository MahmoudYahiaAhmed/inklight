How it works

A real agent with a short leash.

Your words become a typed plan. Plans never come from document text, so an instruction hidden inside a PDF can't change what the agent does.

READ

Indra OCR

Uses a PDF's own text layer first and OCRs only where needed. Keeps layout blocks, reading order, boxes and per-line confidence.

PLAN

Typed steps

Intent, fields and conditions are parsed into a plan of allow-listed tools. There is no shell and no code execution.

ACT

Bounded run

Step limits, time budgets, retries and cancellation. Arithmetic is done in exact decimals, not by a model.

VERIFY

Evidence check

Tells you how it read your request and anything it could not apply. Citations are matched against the stored text, totals are cross-checked, and currencies are never mixed.

Small-model intelligence

Under 200M parameters each, used where they're strong.

We measured a 135M model as the planner on 40 requests. It picked the right task 27.5% of the time, so it doesn't plan. Rules plan the work. Small models point at evidence and rank passages, and code does the maths.

Built for untrusted documents

Local first. Safe by construction.

Prompt injection is data

"Ignore previous instructions" inside a PDF is detected, reported, and has no effect on the plan.

Writes need permission

One tool can write, only into your output folder, never overwriting, and only after --out, --yes or your confirmation.

Nothing leaves the machine

No API key and no telemetry. A stronger remote model is opt-in, https-only, and its quotes are verified against your document.

Two minutes to first answer

CLI, Python, or the local workspace.

Python 3.11+ on Windows, Linux or macOS. Indra's OCR models (~76 MB) download on first use. inklight models pull adds the small models (~100 MB). After that, everything runs offline.

# the shell
pip install inklight
inklight process ./documents/
inklight ask ./documents/ "Find all invoices above $5,000"
inklight serve        # http://127.0.0.1:8765

# Python
from inklight import DocumentAgent
agent = DocumentAgent()
result = agent.ask("Extract the invoice number, date, and total",
                   files=["invoice.pdf"])
print(result.answer, result.sources[0].cite())
