# Third-party licenses and model-license audit

Inklight's own source code is licensed under **Apache-2.0** (see `LICENSE`). Inklight does **not**
bundle or redistribute any model weights: every model below is downloaded by the user, from its
original publisher, under that publisher's license. Audit date: 2026-10-23. This is an engineering
summary, **not legal advice** — read the original licenses before commercial use.

## ⚠ Read this before commercial use: Indra OCR model weights

| Component | License | Source |
|---|---|---|
| `indra-ocr` Python package (code) | Apache-2.0 | https://github.com/datalab-to/indra |
| Indra OCR **model weights** (~76 MB, downloaded on first OCR run) | **Modified OpenRAIL-M** | https://huggingface.co/datalab-to/indra-ocr/blob/main/LICENSE |

Key terms of the weights license (summary of Attachment A and §§4, 7, 8 — verify against the text):

- **Free** for research, personal use, and organisations under **$20M** gross revenue in the prior year
  **and** under $20M total funding raised.
- **Commercial use is restricted** if you provide a product or service that **competes with
  Datalab's** products or services. "Competes" is not defined. A document-AI product built on Indra
  (which is what Inklight is) may fall under this restriction — **obtain a license from Datalab**
  (https://www.datalab.to/pricing) or swap the OCR engine before commercial distribution.
- Redistribution of the weights requires passing the use restrictions downstream, including a copy of
  the license, attribution, and change notices. The share-alike clause (§8) extends the license to
  derivatives and, as written, to outputs.
- The licensor may remotely restrict usage or update the model (§9).

How Inklight handles this:
- Inklight never ships Indra weights; `indra-ocr` fetches them from Hugging Face under Datalab's license.
- The OCR layer is pluggable (`inklight.ocr.register_engine`), so a deployment that cannot accept
  these terms can register a different engine (for example Tesseract, Apache-2.0) without changing the agent.
- The README states this restriction prominently.

## Small language models (optional, fetched by `inklight models pull`)

| Role | Model | Params | License | Notes |
|---|---|---|---|---|
| Reader (extractive QA) | `distilbert/distilbert-base-cased-distilled-squad` via ONNX export `Xenova/distilbert-base-cased-distilled-squad` | 66M | Apache-2.0 (base model card) | The ONNX conversion repo declares no license of its own; it inherits the base model's. |
| Embedder | `BAAI/bge-small-en-v1.5` via `Xenova/bge-small-en-v1.5` | 33M | MIT (base model card) | Same note about the conversion repo. |
| Writer (optional) | `HuggingFaceTB/SmolLM2-135M-Instruct` (official ONNX files) | 135M | Apache-2.0 | Off by default. |

SQuAD (the reader's training data) is CC BY-SA 4.0. That governs the dataset; the model card
licenses the weights as Apache-2.0.
